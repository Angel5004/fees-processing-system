# FEES PROCESSING SYSTEM

## Project Overview

The Fees Processing System is a web-based application developed to simplify and improve the management of school fees. It helps administrators manage pupil records, academic sessions, fee billing, and payments efficiently.

## Project Features

- Pupil management
- Classroom management
- Academic session management
- Fee item management
- Pupil fee billing
- Payment recording and tracking
- Administrative dashboard
- Secure administrator login

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite / MySQL
